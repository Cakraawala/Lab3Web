2. Perbedaan Selektor h1 {...} dengan #intro h1 {...}

Selektor h1 bersifat umum untuk seluruh judul di halaman web, sedangkan #intro h1 hanya berlaku untuk tag <h1> yang berada di dalam elemen ber-ID intro.

<h1> Standar: Berwarna biru rata tengah sesuai deklarasi global.

<h1> di dalam #intro: Berwarna putih dan rata kiri.

Style judul di atas otomatis mengikuti aturan #intro h1 karena berada di dalam kontainer #demo-intro.

3. Pengujian Prioritas Internal, Eksternal, dan Inline CSS

Jika sebuah elemen memiliki deklarasi warna dari Internal CSS (biru) dan Inline CSS (merah), maka browser akan menampilkan nilai dari Inline CSS karena tingkat prioritasnya (*specificity*) paling tinggi.

Teks ini menggunakan class internal (color: blue), namun ditambahkan inline style="color: #c9184a;".

Hasil Pengujian: Teks tampil berwarna MERAH karena Inline CSS mengalahkan deklarasi Internal dan Eksternal CSS.

4. Pengujian ID Selector vs Class Selector

Pengujian pada elemen <p id="paragraf-1" class="text-paragraf">:

Paragraf pengujian selector: id="paragraf-1" (merah, tebal) dan class="text-paragraf" (hijau, miring).

Hasil Pengujian: Teks tampil berwarna MERAH karena ID Selector memiliki bobot spesifitas lebih tinggi (100) dibandingkan Class Selector (10). Namun gaya miring (*italic*) dari Class tetap diterapkan karena propertinya tidak bertabrakan (*cascading*).
